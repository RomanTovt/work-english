WORK ENGLISH — ВЕРСИЯ 2 · УРОВЕНЬ «НА СЛУХ»

ПЕРЕХОД С ВЕРСИИ 1 БЕЗ ПОТЕРИ ПРОГРЕССА
1. В старом приложении нажми «Сохранить копию», чтобы скачать JSON.
2. Скачай Work_English_Android_v2.html и открой в Chrome.
3. Если прогресс не появился автоматически, нажми «Восстановить из копии» и выбери скачанный JSON.
4. При обновлении PWA по прежнему HTTPS-адресу данные того же сайта обычно останутся, но резервная копия обязательна для надёжности.

ДВА УРОВНЯ
- Уровень 1: читаешь вопрос на английском и говоришь ответ.
- При оценке «Знаю» карточка переходит на уровень 2.
- На уровне 2 в режиме «По уровню» вопрос только озвучивается; текст спрятан, пока не откроешь образец.
- Нажми «Вопрос», чтобы прослушать ещё раз, и «Ответить голосом», чтобы продиктовать.
- «Ещё раз» возвращает карточку на уровень 1; «Трудно» сохраняет уровень 2 и повторит завтра.
- Режим «Только на слух» позволяет потренироваться на слух без ожидания оценки «Знаю».

РАСПОЗНАВАНИЕ ГОЛОСА
- В веб-приложении на HTTPS Chrome может распознавать речь при разрешении доступа к микрофону. Возможно потребуется интернет.
- При открытии скачанного HTML (file://) прямое распознавание через браузер может быть недоступно. Тогда нажми «Ответить голосом», тапни поле ответа и используй микрофон клавиатуры Android (например Gboard). Можно просто произносить ответ и самому сверять его.
- Программа сравнивает распознанный текст с одним образцом. Она не умеет надёжно оценить альтернативные формулировки, грамматику, смысл и качество произношения. Итоговую оценку ставишь ты.
- При голосовом распознавании браузер может отправлять аудио на внешний сервис. Прогресс и карточки хранятся только локально.

ПУБЛИКАЦИЯ КАК PWA
Распакуй ZIP на любой HTTPS статический хостинг. Открой ссылку в Chrome Android и выбери «Установить приложение» или «Добавить на главный экран». После первого запуска карточки кэшируются для офлайн-использования, но распознавание речи зависит от наличия сети/браузера.

СОХРАНЕНИЕ
Прогресс и собственные карточки в localStorage браузера. Доступны экспорт JSON и восстановление копии версии 1 или 2. В комплекте 100 диалогов и 10 рабочих тем.
